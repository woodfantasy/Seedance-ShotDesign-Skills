## Standard generation: 4–30s

Required fields: asset roles if any, one-line concept, visible story/action, camera, sound, global continuity/negative constraints.

```text
【素材说明】
@图片1用于[身份/服装/场景/首帧]；@视频1仅用于[动作/运镜/节奏]；@音频1用于[音色/BGM]。

【一句话概述】
[主体]在[地点]完成[事件]，[题材/风格]，[核心镜头语言]。

【时间轴】
0-X秒：[画面、动作、镜头、对白、音效]。
X-N秒：[由上一段状态自然延续的画面、动作、镜头、对白、音效]。

【全局补充】
[角色/服装/道具/场景/光影/音频连续性]。不要[与任务相关的 unwanted elements]。
```

## Complex 30-second generation

```text
30秒[名称/一句话基调]。

【多模态参考层】
[每项素材的用途、范围、禁止迁移内容]。

【全局设定】
环境与质感：[时间、地点、氛围、物理质感]。
视觉风格：[媒介、色彩、景深、光线]。
镜头语言：[全片机位逻辑和运动能量]。
角色/主体：[身份、辨识特征、服装、道具、比例]。
表演核心：[可见动作 + 可选潜台词]。
全局限制：[声音、字幕、连续性、不要出现的内容]。

【时间戳剧本】
[00:00-00:05] [阶段名]：[动作/物理指令]；[镜头]；[对白/音效]；[必要时写导演潜台词]。
...
[00:25-00:30] [收束]：[动作因果和清晰结尾]。
```

## Ultra-long video: 30–180s

```text
全片时长[XX秒]，画幅[比例]，分辨率[480p/720p]，[一句话类型与基调]。

【素材与角色 Bible】
[角色身份、面孔、发型、服装、道具所有权、声音和参考范围]。

【故事概述】
[开端 → 发展 → 转折 → 高潮 → 结尾]。

【全局连续性】
[风格、时间/天气、场景地理、角色不变量、音频设计、禁止项]。

[00:00-00:20] 第一幕：[本段叙事目标、动作因果、镜头和声音]。
[00:20-00:45] ...
[最后时间段]：[回收主线并形成明确结尾]。
```

## Video extension

### Continuous extension

```text
参考@视频1，向[前/后]延长[新增秒数]秒。提示词仅作用于新增部分，原视频保持不变。
交接状态：@视频1的[首/尾]帧中，[角色位置、朝向、动作动量、镜头运动、光线、声音]。
0-X秒：[无切镜地延续动作与运镜]。
X-N秒：[新增事件和收束]。
保持@视频1的[身份、服装、场景地理、光照、色调、声音]一致；禁止生硬切镜、位置重置或物体凭空出现。
```

### Transition extension

```text
参考@视频1，向后延长[N]秒。原视频保持不变。
[转场类型]：镜头A为[源末尾状态/景别]；[遮挡物/相似形/动作/焦点]在连接点保持[位置、尺寸、方向、速度]；过渡到镜头B的[新场景/新景别]。
0-X秒：[建立转场触发]。
X-N秒：[转场后事件]。
要求连接自然，无黑屏、跳帧、闪烁、硬切或主体突变。
```

## Smart editing

```text
编辑@视频1。
修改对象：[具体对象]。
变化：[原状态A] → [目标状态B]。
生效时段：[全片 / X-Y秒 / 从第X秒逐渐出现]。
保持不变：[人物、动作、镜头、背景、字幕、声音、构图、光影中不应被改动的部分]。
[被删除区域如何补全 / 新元素如何匹配透视、光照和材质]。
```

## Advanced/video editing with annotation

```text
[红框内 / 蓝色箭头指向 / 地标点处 / 红线左侧]的[具体对象]，
从[状态A]修改为[状态B]，仅在[X-Y秒]生效。
保持[其余对象、人物身份、动作轨迹、镜头、背景、画质、色调和音轨]不变。
```

## Spatial viewpoint modification

```text
将@视频1的[原机位/视角]修改为[目标机位/视角和运动路径]。
保持[人物身份、动作时序、场景布局、物体比例、光线方向]不变。
根据原场景空间关系自然补全新视角可见区域，不新增无关物体，不改变动作因果。
```

## BGM separation

```text
编辑@视频1：完全移除背景音乐/BGM。
保留：[人物完整对白、笑声、呼吸、指定环境音、指定动作音效]。
画面保持：[人物、动作、字幕、构图、画质、色调]完全不变。
不得修改人声音色、语气、声场或口型同步；不得添加新音乐或新音效。
```

## Creative transfer

```text
参考@视频1的[创意形式、镜头轨迹、节奏、情绪、喜剧机制、转场逻辑]，
将主体替换/重构为@图片1的[新主体]，场景为[新场景]。
必须保留：[选定的创意内核]。
不要迁移：[原人物、原背景、品牌、水印、无关道具或原音轨]。
保持新主体的身份、外形和场景逻辑稳定。
```

## Voice and multilingual dialogue

```text
角色[名称/@图片N]使用[目标语言]说：“[exact line]”。
音色参考@音频1，仅参考[声线、年龄感、语流、情绪]，不要把参考音频当作BGM。
演绎：[低沉悬疑/克制悲伤/活泼带货等]；断句：[说明]；口型与目标语言发音同步。
字幕：[无字幕 / 仅显示目标语言字幕，准确文本为“...”]。
```

## Green-screen editing

```text
将@视频1的绿幕前景主体合成到@图片1/@视频2的[目标环境]。
保留前景主体的身份、动作和时序；移除全部绿色背景、绿色溢色和边缘残影。
匹配目标环境的透视、机位运动、光线方向、色温、接触阴影、景深和环境反射。
[新增交互与时间点]。禁止出现贴片感、边缘闪烁或背景漂移。
```

## Rough white model

```text
@视频1是粗颗粒白模，只参考[动作、动线、运镜、角色站位、遮挡、光影变化、切镜节奏]。
映射：[颜色/形状模型] → @图片1的[角色]；[...] → @图片2的[道具/场景]。
[按时间线描述剧情、完整肢体动作和互动因果]。
场景：[文字或@图片N]。最终风格/材质/光影：[要求]。
不要保留白模材质、灰色背景、辅助线或未指定模型。
```

## Fine white model

```text
将@视频1的细颗粒白模动画渲染为最终成片。
0-X秒：[环境、色调、材质、光影、特效]。
X-N秒：[转场触发与后续渲染]。
场景参考@图片1；[人物/物体]材质[保持不变/随场景变化]。
去除轨迹线、坐标线、相机锥体和视口辅助信息，保持几何结构、机位和动作时序。
```

## Seamless transition between two videos

```text
将@视频1和@视频2无缝衔接，不修改两段原视频本身。
连接设计：@视频1尾帧的[锚点]以[方向/速度]运动并[遮挡/填满/变形]画面；过渡为@视频2首帧的[对应锚点]。
在连接点保持锚点的形状、位置、尺寸、运动方向、速度、光线或色彩连续。
情绪从[A]过渡到[B]。生成的桥接段不得出现黑屏、跳帧、硬切、闪烁、文字或主体突变。
```

## Multi-panel storyboard

```text
@图片1是一张包含[N]个连续镜头的分镜图，每一格代表[完整镜头/人物/场景]，阅读顺序为[顺序]。
角色映射：分镜中的[A]对应@图片2的[角色]；[B]对应@图片3。
镜头1（0-X秒）：[补全构图、景别、动作、运镜、声音，以及与下一格的连接]。
...
全局保持[人物、服装、比例、场景地理、光照和风格]一致；不新增无关角色或道具。
```
